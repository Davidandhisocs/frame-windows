# FB Frame Counter

Practice recording, replay and 240 Hz frame-window analysis for Geometry Dash. Free, with no online requirement.

Runs on Windows, macOS and iOS.

## Status

Early rebuild. Right now the mod adds a **Frames** button to the pause menu. Coming next:

- Macro import (GDR2, 240 Hz)
- Practice-mode recording
- Frame-window analysis by replay
- Click circles, frame counters and sounds during playback

## Settings

Choose which frame numbers and ranges appear as counter rows (for example `1,2,3,7-8`), the maximum circle width, counter size, and custom sounds per frame width.
